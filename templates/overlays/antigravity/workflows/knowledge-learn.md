# Knowledge Learn Workflow (Antigravity Edition)

## Goal
Capture architectural decisions, debugging solutions, and implementation patterns.

## Process
1. Identify a critical piece of information that was learned during the session.
2. Log the finding to `.omni/knowledge/` as per the standard workflow.
3. **Antigravity Enhancement:**
   - Explicitly ask the user if they want to save this as a **Knowledge Item (KI)**.
   - KIs are preferred for:
     - Project-wide architecture decisions.
     - "Landmines" (things that broke and how to avoid them).
     - Unique environment setup steps.
4. When creating a KI, provide a clear, searchable title and a concise description.
